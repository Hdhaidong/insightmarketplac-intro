# insightmarketplac

> 闭源 AI 数字员工平台：以 **CRM** 为业务底座，完整覆盖**记忆引擎 × 多智能体编排 × 本地交付 × 治理审计**四大能力域。一套交付，不开源，接受定制。

**介绍页（GitHub Pages）**：<https://hdhaidong.github.io/insightmarketplac-intro/>

---

## 这是什么

insightmarketplac 是一套以 CRM 为业务底座的 AI 数字员工平台，数字员工需要的能力域这里全部齐备：

| 能力域 | 能力覆盖 |
|---|---|
| **记忆与洞察 · AI 记忆引擎** | 沟通数据自动捕获 → 客户全景档案 → 每日简报与战术预警 → 上下文跟进内容生成 |
| **编排与护栏 · 多智能体编排** | 多智能体任务编排、护栏与输出校验、错误恢复、可视化工作流编排、多类节点资产 |
| **本地与交付 · 本地交付体系** | 本地设备操控、真实成果落盘交付、连接器生态、后台定时任务与多角色协作 |
| **治理与审计 · 可控执行治理** | 人工审批门控、全量审计留痕、证据链留档、数据本地化 |

## 记忆引擎闭环

捕获 → 记忆 → 洞察 → 行动：

1. **数据捕获** —— 沟通、审批、阶段变更自动沉淀进客户时间线，零手工录入
2. **记忆构建** —— 客户全景档案动态更新：阶段、互动频次、在途商机、标签画像
3. **洞察提炼** —— 每日简报 + 战术预警：沉默客户、临期商机、到期任务自动浮出
4. **行动执行** —— 基于上下文生成跟进内容，一律进入待审批队列

## 平台架构

四层 + 一条治理纵轴：

1. **数据连接层** —— 本地优先、多源接入（Excel / 连接器 / 本地文件），数据不出域
2. **本体语义层** —— 客户、联系人、线索、商机、任务建模为对象与关系，属性动态更新
3. **执行回写层** —— P-E-V 三段式执行链（Planner → Executor → Verifier），批准后回写并留证
4. **智能协同层** —— AI 提案、人拍板，护栏内置，无自动发送
5. **治理贯穿** —— 权限控制、全量审计、证据链可回溯

## CRM 底座

数字员工长在 CRM 上，记忆与行动全部围绕客户资产展开：

- **九阶段客户管线** —— 待联系 → 已联系 → 已确认 → 方案演示 → 谈判中 → 已成交 → 合作伙伴，流失 / 未入线单独归口
- **客户时间线** —— 沟通、审批、治理动作自动沉淀，系统记录专属标识、不可删除
- **审批中心** —— 邮件草稿先进待审批队列，批准后才可发送
- **客户全景摘要卡** —— 阶段、互动频次、在途商机、标签画像一屏读完
- **每日简报与战术预警** —— 沉默客户、临期商机、到期任务自动浮出
- **本地数据库 + Excel 导入** —— 数据本地存储不出域，存量客户资产一次导入

## 业务场景 · 客服对接

多渠道统一接入 → 客户上下文自动组装 → 记忆驱动回复起草 → 人工审批门控 → 时间线自动沉淀。发送权永远在人手里，客户数据全程不出域。

## 差异优势

- **闭源交付，接受定制** —— 工作流、连接器、角色分工、报表口径按业务定制
- **数据归属可控** —— 支持本地 / 内网部署，客户资产与沟通记录不出域
- **人工审批门控** —— 自动化产物一律先进待审批队列，发送权与执行权保留在人手里
- **全链路审计留痕** —— 每次写操作与 AI 执行均可回溯
