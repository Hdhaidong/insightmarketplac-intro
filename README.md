# insightmarketplac

> 吸收 **AutoManus × MARCO × OpenWorker** 三大体系能力的闭源 AI 数字员工平台。一套交付，完整替代；不开源，接受定制。

**介绍页（GitHub Pages）**：<https://Hdhaidong.github.io/insightmarketplac-intro/>

---

## 这是什么

insightmarketplac 把当前三类代表性 AI 员工产品各自最强的能力面，收进同一个产品底座：

| 能力来源 | 吸收的能力面 |
|---|---|
| **AutoManus**（云端 AI 业务员） | AI 记忆引擎四层闭环：沟通数据自动捕获 → 客户全景档案 → 每日简报与战术预警 → 上下文跟进内容生成 |
| **MARCO**（多智能体编排框架） | 多智能体任务编排、护栏与输出校验、错误恢复、可视化工作流编排 |
| **OpenWorker**（本地优先 AI 同事） | 本地设备操控、真实成果落盘交付、连接器生态、后台定时任务与多角色协作 |

## 平台架构

参照 Palantir Foundry 的企业级架构范式，四层 + 一条治理纵轴：

1. **数据连接层** —— 本地优先、多源接入（Excel / 连接器 / 本地文件），数据不出域
2. **Ontology 本体层** —— 客户、联系人、线索、商机、任务建模为对象与关系，属性动态更新
3. **Actions 执行层** —— P-E-V 三段式执行链（Planner → Executor → Verifier），批准后回写并留证
4. **AIP 协同层** —— AI 提案、人拍板，护栏内置，无自动发送
5. **治理贯穿** —— 权限控制、全量审计、证据链可回溯

## 差异优势

- **闭源交付，接受定制** —— 工作流、连接器、角色分工、报表口径按业务定制
- **数据归属可控** —— 支持本地 / 内网部署，客户资产与沟通记录不出域
- **人工审批门控** —— 自动化产物一律先进待审批队列，发送权与执行权保留在人手里
- **全链路审计留痕** —— 每次写操作与 AI 执行均可回溯

## 合作方式

本项目**不提供源码、不接受 fork 改造**，仅以定制项目形式合作：

1. 需求沟通 —— 梳理业务流程与要替代的人工环节
2. 方案设计 —— 输出能力清单与工作流设计
3. 定制交付 —— 闭源打包交付，支持本地部署
4. 持续支持 —— 上线陪跑与迭代扩展
